## ① E-a 块级主动预挂载（R10 立项遗留兑现）

**问题**：块公式（LaTeX 块）/代码块 nodeview 挂载是同步重活
（CodeMirror+Vue+KaTeX），由共享 IO 800px 带触发；cv 档下 IO 对无布局几何
子树滞后（R10 S-g 定罪），挂载完成时块已在视口内——解题技巧档全程
**24/24 全可见**（基线 ×3 一字不差），即用户"第一次滚到的块刷新闪烁"的主载体。

**原型机制**：滚动输入驱动的预测式预挂（行内 R10 Fix-A 同思路）——rAF 帧内
扫描滚动方向前方预测带（视口沿 + 800px + 最近步进余量）内仍是占位 pre 的
块，经补丁侧受控触发器走**与 IO 进带完全相同**的挂载路径（幂等，IO 兜底保留）。

**安全约束**：
- 限速：每帧最多 1 块（perFrame 可调），不在 wheel/IO 回调里同步挂载；
- 上滚侧只预挂"曾挂载过"的块（teardown 冻结高语义），首挂块留给 IO 原路径
  （R4-①/R6 Fix-B 无锚定补偿约束）；
- M3 块挂载率 100% 硬门不受影响（预挂只提前不替代）。

**实测数据（阶段五，dev 解题技巧档 down-slow，ABAB 交错——base ×6 / fix ×3
+ 抽查臂）**：

| 场景 | 基线 E1 可见 | 原型臂 E1 可见 | 说明 |
|---|---|---|---|
| down-slow（主门） | 24/24/24 + 24/24/24（六臂一字不差） | **0 / 0 / 1**（中位 0，**-100%**） | 门（-80% 且 ≤2）双达标 |
| down-fast | 16 | **1**（-94%） | |
| revisit（下+上滚 20s 窗） | （1MB 档 29 可见/13 remount） | 48 块 **0 可见**（含上滚 remount 路径） | 上滚安全门生效 |
| 1MB fresh-down-fast | 7-8/8 | 5/10 | 快滚步进（1200px）穿透 800px 带的 outrun 残留（E2 范畴，行内侧为主） |

**限速与帧代价证明（§8 条款）**：
- 单块挂载耗时：解题技巧档 3~10ms（lastMountMs 全序列），1MB 档最大 32.3ms；
- perFrame=1 → **最坏单帧预算 = 单块挂载 ≈ 10ms（1MB ≈ 32ms）**，远低于
  R1b 教训量级（300-700ms 整批长任务），且不发生在 wheel/IO 回调内（rAF）；
- 帧代价：fix 臂 gapP50=6ms / p95 6-12ms，与 base 一字不差（零帧代价）；
- M3 完整性：全程 phInBand=0、katex-error=0、M1/M2=0（挂载率 100% 硬门保持）；
- M 侧统计：sweeps 89 / triggered 24 / mounted 24 / skippedUp 0（解题技巧
  down-slow 典型臂）。

**待拍板项**：是否默认开启；bandPx（800）/perFrame（1）默认值；
上滚侧是否放开首挂（需另配高度预留）。

## ② P3 盒预留预热（R5 留档 → R6/R8 呈报 → 本轮第三次，附实测否证）

**原案预期**（R8 ⑤）：预热批渲染态测高 → hasReservedBox 覆盖全文档 → 冷区
队列不积压、首渲块高零变化 → 1MB p95 199→~130。

**本轮实测**（R10 后代码，scroll-abab 1MB 同批 ABAB，on 臂）：

| 臂 | p50 | p95 | over100 |
|---|---|---|---|
| 基线 ×5 | 58.6/65.6/69.4/64.7/64.2（中位 64.7） | 172~186（中位 175.8） | 183-208 |
| P3 原型 ×3 | 64.9/64.1/63.4（中位 64.1，**-0.9%**） | 172.7/175.5/171.2（中位 172.7，**-1.7%**） | 179-192 |

**结论：R8 投影在本轮不复现**（差值噪声级）。归因：R8 时代的队列积压主成分
已被 R10 Fix-A/A'（预测式发现 + jump 同步直绘）消化；本轮 P 归因显示现存墙
主成分是**冷区块级首变现布局链**（layout:block 553 + layout:height 544 ≈1:1
伴随全程），行内盒预留不触及该层。

**建议**：P3 按原案**不采纳**（无实测收益）；原型保留在库（默认关）供
E-b 残余路径后续复验。若未来重开，方向应转向块级高度表保真（cv 预热吞吐），
属另一立项。

## ③ 连带说明（E-b/E2 与 P1 的关系）

E-b（1MB 冷区穿越可见换装 124~134/全程）与 P1 同源（同一批冷区块）。本轮
已证：冷缓存窗口假设不成立（全程分布）、P3 无效、常量路径（JUMP_SYNC_CAP
同步冷算扩展/泵预算）全部红线 1 锁死——**E2/P1 的进一步收敛需拍板级变更**
（如同步冷算上限或块级预热吞吐），本轮按"归因留档"收口。
