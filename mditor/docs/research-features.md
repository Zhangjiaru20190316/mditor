# 科研与学习功能语法规范（v4.7 知识功能套件）

本文档是五个知识功能模块的**最终语法规范与设置说明**：全库索引 + 快速切换器（模块 1）、双向链接（模块 2）、学术引用链 + LaTeX 导出（模块 3）、间隔重复闪卡（模块 4）、库级 AI 问答（模块 5）。样例验收文档见 [demo.md](./demo.md)。

设计总则（全部模块共享）：

- **本地优先**：索引、闪卡进度、向量索引只存内存或 `appDataDir`，无遥测、无上传；需要联网的只有 AI 对话与嵌入请求，且全部经 Rust 侧代理（渲染层不直连外网，CSP 不变）。
- **语法解析恒开启**：双链 / 引用 / 闪卡的 remark 解析无条件注册（保证文件互通与解析管线一致，见 `lib/remarkPipeline.ts` 的哨兵契约）；设置开关只控制交互功能面。
- **语法降级**（导出铁律）：所有自定义语法在导出 HTML / PDF / PNG / Word / LaTeX / 复制富文本时有降级路径——双链 → 标准链接或纯文本；引用 → 编号纯文本 + 参考文献表；闪卡 → 普通引用块（blockquote）；图表标记 → caption 文本。导出产物离开本工具仍可读。

## 模块 1：全库索引 + 快速切换器（Ctrl+P）

- 扫描 workspace 全部 Markdown 文件，维护轻量内存索引（标题 / 大纲 / 双链 / 标签 / 闪卡 / mtime）；**不落盘**。
- 扫描分批（≤50 文件/批）+ idle 调度；保存与文件监听走单文件增量更新。大文档性能模式开启时，用户输入/滚动期间扫描让路。
- **Ctrl+P** 唤起快速切换器：模糊匹配文件名 + 标题，按最近打开加权；`>` 前缀预留命令面板（本期未实现）。

设置：`设置 → 知识功能 → 全库索引`（默认开）。

## 模块 2：双向链接 + 反链面板 + 标签

```
[[目标笔记]]              链接到按文件名（去扩展名）匹配的笔记
[[目标笔记|显示文本]]     带显示别名
[[目标笔记#标题]]         指向笔记内标题（# 之后的部分当前仅用于显示）
```

- 输入 `[[` 弹出补全（数据来自全库索引）；完成 `]]` 即时成 chip；点击 chip 跳转；重名目标按路径消歧提示。
- 侧栏「链接」页：反向链接（引用当前文档的所有来源 + 前后各一行上下文）与全库标签面板（点击过滤）。
- 行内 `#tag`：仅识别**非行首**位置（行首 `#` 是标题，参照 Obsidian 规则），字符集含字母/数字/CJK/下划线/连字符/斜杠（层级标签）。
- 导出降级：索引能解析 → 标准相对链接；未解析 → 纯文本 + 样式提示。

设置：`设置 → 知识功能 → 双向链接`（默认开；解析恒开启）。

## 模块 3：学术引用链 + LaTeX 导出

### 行内引用

```
[@citekey]                单条引用
[@citekey, p. 12]         带定位符（页码/章节）
[@k1; @k2] / [@k1,k2]     多条引用（; 或无空格逗号分隔）
[@k1; @k2, ch. 3]         多条 + 定位符
```

- 定位符规则：**最后一个含空白的逗号后缀**视为定位符；`[@k1,k2]` 的无空白逗号视为键分隔。
- citekey 大小写不敏感；未解析键在渲染/导出中保留键名文本（如 `[ghost2099]`），不进参考文献表、不占编号。
- 编辑器内 chip 统一显示**作者-年份形态**（便于识别；编号依赖全文序，由静态渲染与导出统一处理）。

### 参考文献表（自动生成）

在文档末尾放置标记标题（H1 或 H2，忽略大小写与冒号）：`# References` / `## References` / `# 参考文献` / `# 参考资料`。

- 标题与下一个同级/更高级标题之间的旧内容被**自动生成的文献表替换**（标记处即生成区，手写占位会被覆盖）。
- 编辑器内：标题下出现「由文献库自动生成」widget（只读展示，不进文档）。
- 静态渲染（AI 面板等）与导出：直接输出编号列表。
- 两种样式（`设置 → 知识功能 → 引用样式`）：
  - **numeric**（默认）：`[1]` 行内编号（按全文首次引用序）+ 引用序文献表；
  - **author-year**：`(Smith & Lee, 2020)` + 第一作者字母序文献表（APA 简化形态）。

### 文献库（.bib）

- `设置 → 知识功能 → 文献库 (.bib)` 选择 BibTeX 文件（Zotero / Better BibTeX 导出）。
- 自研解析器：`{}` / `()` / `""` 定界、`@string` 缩写展开、`#` 拼接、花括号嵌套与转义；坏条目跳过并告警（引用选择器顶部提示），不中断整体解析。
- 选区工具栏「@」按钮 / 菜单「编辑 → 插入引用 [@]…」打开引用选择器（按 citekey / 标题 / 作者 / 年份检索）。

### 图表编号与交叉引用

```
![标题文字](image.png){#fig:myid}     图片属性（同段尾随或下一段独立成行）
: 表格标题 {#tbl:myid}                表格说明行（表格的前一行或后一行）
见 @fig:myid / 如 @tbl:myid 所示       正文引用 → 「图 1」/「表 2」
```

- 编号按文档出现序（图、表独立计数）；渲染为斜体 caption「图 N：标题」（无 alt 的图仅「图 N」）。
- 编辑器内不实时编号（remark 不随键入重跑，与公式自动编号同款决策）；静态渲染（AI 面板等）与导出生效。
- `: caption`（无 id）不参与编号，保持原样；未定义 id 的 `@fig:x` 保留原文。
- code / inlineCode / 公式内的标记保持字面。

### LaTeX 导出

菜单「文件 → 导出 LaTeX (.tex)」：纯前端 md→tex（**不调 pandoc、无 shell 权限**）。

- 文档类 `ctexart`（XeLaTeX 编译，含中文），预置 amsmath / graphicx / booktabs / hyperref / ulem / geometry。
- 首个非 References 的 H1 作为 `\title`（其余标题整体上移一级）；公式源天然平移（`$…$` / `equation`）；`[@key]` → `\cite{key}`（定位符 → 可选参数）；References 标题 → `thebibliography`；图片 → `figure` 环境（`\caption`/`\label`）；GFM 表格 → `booktabs` 风格 `tabular`（对齐映射，单元格块级内容降级为纯文本）；双链 → 纯文本显示名；原生 HTML 剔除。
- 图片按原路径 `\includegraphics`——.tex 与图片需同目录分发。

## 模块 4：间隔重复闪卡

### 卡片语法（directive 容器）

```
:::flash
问题：什么是间隔重复？
---
答案：按记忆曲线调度复习的算法。
:::
```

- 容器内 `---`（首个）分隔问题/答案；多行文本拼接为一段。
- 编辑器内渲染为卡片样式块（内容可直接编辑）；空段输入 `:::flash` 即时成卡（预填问题段/分隔线/答案段骨架）。
- 代码围栏内的 `:::flash` 字面保留；未闭合容器整体保持原样（不开卡不吞正文）。

### 做卡入口

- 选区工具栏「卡」：打开做卡弹层（答案预填选中文本，可调）；
- 选区工具栏 AI 菜单「改写为问答卡」：AI 生成 Q/A → 做卡弹层人工确认（支持「AI 重新生成」）后插入。

### 复习调度（SM-2 简化版）

- 间隔表 `[0, 1, 3, 7, 14, 30]` 天 × ease 因子（实际间隔 = `table[box] × ease / 2.5`；ease 起步 2.5、±0.15 微调、下限 1.3）。
- 四档自评：**忘了**（box 归零、ease −0.15、当天再现）/ **困难**（box 不变、ease −0.15）/ **良好**（box +1）/ **轻松**（box +1、ease +0.15）；box 封顶 5。
- 复习模式：菜单「视图 → 复习闪卡…」——翻面（空格）→ 四档自评（1-4 键）；显示逾期状态与来源笔记（点击跳回原行）。
- 进度存储：`appDataDir/review-state.json`（卡片键 = 文件路径 + 问答内容哈希 FNV-1a）；文件改动后哈希失配的进度卡在结束页汇总提示「需重定位」（不自动迁移）；进度文件损坏静默重建。
- 到期扫描：全库索引的 `flashcards` 字段（保存/监听增量更新，不回读文件）。

导出降级：闪卡块 → 普通引用块（内容原样保留）。

设置：`设置 → 知识功能 → 间隔重复闪卡`（默认开；解析恒开启）。

## 模块 5：库级 AI 问答（RAG，默认关闭）

- `设置 → 知识功能 → 全库问答 (RAG)` 开启并配置**嵌入服务**（OpenAI 兼容 `/embeddings`；Base URL / API Key / 模型独立于对话模型，如 `text-embedding-3-small`）。
- AI 面板输入框上方「全库问答」开关 + 「构建索引」：
  - **首次构建有成本确认**（明示「将调用嵌入 API 处理 N 个文档」），确认后才开始；
  - 构建分批（≤16 块/批）后台进行，**可暂停/续跑**（暂停即落盘保留进度）；大文档性能模式下用户活跃时让路；
  - 增量更新两层去重：文件 mtime 未变不读盘；块内容（id+哈希双校验）未变不重复嵌入——日常保存只对真正改动的块计费；换嵌入模型自动全量重建。
- 分块：按标题分节，~1200 字符/块（≈500 token），块间重叠 1 句，块文本带「文件标题 > 节标题」语境前缀。
- 问答：问题嵌入 → 余弦 top-8 → `<source>` 上下文经对话模型流式回答；回答下方展示**可点击来源列表**（文件名 › 标题，跳转对应笔记对应标题）。
- 检索失败静默回退普通对话模式；功能默认关闭、关闭时自动暂停构建。
- 向量索引只存本地 `appDataDir/rag-index.json`（向量 4 位小数控制体积）；嵌入请求经 Rust `ai_embed` 代理——**渲染层不直连外网，CSP 不变**。
