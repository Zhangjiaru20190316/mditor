# 开发者模式错误代码表（MD-XXXX）

开启开发者模式（设置 → 性能与诊断）后，应用把运行时异常归类为稳定错误代码。
用户反馈问题时直接引用代码（如「MD-1001 又出现了」），配合「复制报告」按钮
或应用数据目录 `logs/` 下的 `dev-anomalies.log`（每条异常附环境快照、最近
操作、文档概况）即可定位。

- **error 级**（告警卡 + 原生弹窗）：5001 / 5002 / 5003 / 5011
- **warn 级**（仅右上角告警卡）：其余全部代码
- 同一代码 60 秒内多次出现只弹一张卡（计数照常累计）；
  info 级事件只进诊断面板与日志，永不弹卡。

## MD-1xxx 滚动 / 布局

| 代码 | 含义 |
| --- | --- |
| MD-1001 | ghost 滚动——无用户输入、无已知程序写入的不明滚动（「页面自己动」） |
| MD-1002 | 视口内容大幅位移（>24px，非用户/尺寸变化引发） |
| MD-1003 | 主线程阻塞超过 1 秒 |
| MD-1004 | 文档高度突变（>1500px） |
| MD-1011 | ProseMirror 顶层块批量替换（remembered size 随旧元素消亡丢失 → 回落占位高度） |

不计异常的滚动类 info 事件：`viewport:resize`（视口尺寸变化）、
`session:resize`（尺寸变化引发的滚动——开合侧栏/最大化还原/改排版的合理结果）、
`layout:clamp`（浏览器钳制：微位移/贴底钳制）。

## MD-2xxx 编辑命令（按命令类别）

| 代码 | 含义 |
| --- | --- |
| MD-2001 | 编辑命令静默失败（未分类兜底） |
| MD-2011 | 块结构命令失败（移动/复制/删除块、设块类型、表格操作） |
| MD-2012 | 行内格式命令失败（加粗/斜体/行内代码/颜色/链接/脚注） |
| MD-2013 | 文档写入命令失败（setValue/插入/AI 写入/揭示） |
| MD-2014 | 应用/窗口命令失败（退出冲刷/关窗/菜单退出） |

## MD-4xxx 内存

| 代码 | 含义 |
| --- | --- |
| MD-4001 | 堆内存持续增长（泄漏候选：≥50MB 且 ≥2MB/分钟） |
| MD-4002 | ProseMirror 视图残留（重建后旧视图 DOM 未释放） |
| MD-4003 | 内存自愈：编辑器重建 |
| MD-4011 | DOM 节点持续增长（游离 DOM/重建残留候选：≥30k 且 ≥1500/分钟） |

## MD-9xxx 性能 / 渲染

| 代码 | 含义 |
| --- | --- |
| MD-9001 | 持续掉帧（30s 心跳窗内 >50ms 帧间隔 ≥10 次） |
| MD-9002 | 布局抖动风暴（2s 内 ≥3 次大幅视口位移） |
| MD-9003 | 输入响应卡顿（30s 心跳窗内按键→上屏延迟 >100ms ≥8 次） |

## 排查入口

- 诊断面板：设置开启或 `Ctrl+Alt+D`（四总线事件流 / 计数器 / 异常记录 / 批注体检 / 复制完整报告）
- DevTools 控制台：`__devMode.report()`、`__scrollDebug`、`__annoDebug`、
  `__opDebug`、`__sysDebug`
- 日志文件：应用数据目录 `logs/`（`dev-events.log` 全事件流、
  `dev-anomalies.log` 异常附上下文、`memory.log` 内存心跳）
