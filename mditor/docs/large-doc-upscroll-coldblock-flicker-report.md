# R12 结题报告：大文档上滚冷块首挂闪刷/抽搐专项（blockPreMount 上滚侧收口）

> 任务口：用户目标「修复在缓存（cv 档懒渲染）状态下往上滚动卡顿抽搐的问题（向下
> 滚动正常），先归因，再修复」。承接 R11 §⑦ 拍板遗留的「上滚首挂不放开」
> （`docs/large-doc-reveal-flicker-scroll-perf-report.md` ⑤）。
> 探针与测量产物：`perf/tmp-r12/probe-upscroll.mjs`、`perf/results/r12-upscroll-*.json`（6 份）。

## ① 归因（先归因，实锤链）

### 症状复现（解题技巧档 750 公式/24 块级，跳底后慢滚上 6000px vs 跳 10% 慢滚下 6000px）

| 指标（up 臂 vs down 臂，r12-upscroll-…346 基线轮） | up（上滚） | down（下滚） |
|---|---|---|
| 换装可见（占位曾在视口内被观察 + 随后换装，R10 口径） | **3/3 块全可见** | 0 |
| 首挂落入视口（dataset.mnt 无→有那帧块与视口相交） | **3**（冷块 100% 在视口内换装） | 0（3 块全在视口外预挂） |
| 首挂高度突变（占位→真实，块级） | +67.9/+78.3/+63.1px，**全部在视口内** | +73~81px，全部在视口外（无感） |
| anchor-comp 迟到补偿 | **24 次** | 1 次 |
| 大位移帧（视觉口径 \|px\|≥46，修复关对照轮） | 4 帧（46.3/-68/-79.4/-63.1） | 0 |

### 根因机制链（每环实测实锤）

1. `blockPreMount.ts` 上滚安全门（R11 拍板语义）：上滚侧只预挂「曾挂载过」的块
   （`dataset.mnt === "1"`，teardown 冻结高在、重挂零高度变化），**冷块（从未挂载）
   一律跳过**（skippedUp，实测 28 个候选被跳过、0 预挂）。
2. 冷块只能等 IO 原路径——cv 档 content-visibility:auto 下 IO 交叉计算对无几何
   目标不报进带（R10 S-a/S-g 机制），挂载完成落在视口内：占位 pre → CodeMirror
   换装闪刷（3/3 可见）+ CodeMirror+Vue+KaTeX 同步重活卡顿（3~32ms/块）。
3. 首挂高度突变（占位 ~70px → 真实 ~138px）在视口内发生，下方内容被推挤
   （63~88px 视觉跳变）；视口上方高度变化无 overflow-anchor 补偿（global.css
   明确关闭，历史教训），scrollDebug anchor-comp 是两帧确认制——位移帧与补偿帧
   错开 = 用户看到的「内容跳一下又弹回」抽搐（up 臂 24 次 vs down 臂 1 次）。
4. **跳过原因本身成立**（上滚首挂高度变化会推挤视口内容），R11 的保守是对的；
   错的是没有补偿路径可选——直接放开会复现 ③ 的抽搐，跳过则冷块闪刷。缺的是
   「同步补偿」这一环。

### 二段根因（修复中途实测发现）

补丁侧 `@milkdown/components` code-block 的 `updateLanguage()` 用
`loader.load().then(reconfigure)` 挂语言（LaTeX 的 CodeMirror 扩展与 KaTeX 预览）——
语言包缓存命中时 reconfigure 在**微任务**完成（trigger 返回后、paint 前），KaTeX
预览高度在挂载同步返回后仍会变（实测 4 块中 2 块同步补偿只拿到纯文本中间态高度，
残余 66px 位移帧仍在）。同步补偿必须排进微任务才能拿到最终高度。

### 与既有水位的关系（非本轮引入、不宣称消灭）

上滚侧 ±4~28px 小位移帧（cv 变现/行内首渲的上滚结构性残余：上滚时上方预渲染窗
内高度变化直接打在视口锚上，下滚时只推视口外内容）修复前后持平（24↔26 帧/6000px，
±对结构、与块挂载时刻不对齐、down 臂 0 帧）——R8~R11 门禁在案（D1），深层根治
属 P3 级立项（三次呈报未采纳）。另滚动起步处一次性形态（跳底后首滚的 cv 变现批，
-66px 单帧）基线同在，与本轮无关。

### 安全语义说明（对 R4-①/R6 Fix-B 红线的演进，非违反）

上滚首挂的安全前提是「视口上方高度变化不能推挤视口内容」。旧实现用「跳过」满足
（把闪刷留给 IO）；新实现用「同步补偿」满足（高度差当帧补写 scrollTop，视觉零位
移）——安全语义等价于「高度预留」，且消掉了 IO 路径的闪刷与卡顿。防护三重门
保证补偿自身不会放大异常（几何异常/超限/越界即弃）。
