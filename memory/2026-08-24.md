## mditor v4.3.0：开发者模式全面升级（诊断数据 + 错误码细分 + 滚动归因 resize 缺口）

三项任务一次交付（用户规格：广度优先、方案自设计）。v4.2.2 当时还在工作区
未提交，本次一并入库。

### 交付一：滚动归因——视口尺寸变化成为一等信号

- **缺口定罪**：v4.2.1 的 pointerdown window 级意图窗只覆盖「点击触发的布局
  变化」；最大化还原（任务栏点击不进 webview 窗口）、DPI 变化、OS 贴边分屏
  等场景无用户输入信号 → 重排滚动/位移被误判 ghost / MD-1002 / MD-1004
- **方案**：host 挂 ResizeObserver（与 PM 内容宽度探针不同源）记 lastResize
  （at/dw/dh/source 窗口级|容器级）；`viewport:resize` 事件 300ms 节流（拖
  拽侧栏 RO 每帧触发，不节流会冲掉事件环），原始次数进计数器
- **状态机**（stepSession 纯函数）：新增 verdict `{type:"resize"}`，优先级
  **user > write > resize > clamp > ghost**，因果窗 RESIZE_CAUSAL_WINDOW_MS=500
  （CSS 过渡期 RO 逐帧刷新 → 窗口自然顺延）；`session:resize` info 事件不计
  ghost 不弹卡；同窗 layout:shift/height 降 info 带 `cause="resize"`，分析器
  对 MD-1002/1004 加 `cause!=="resize"` 纵深防御
- **灵敏度红线单测自证**：resize 过期 600ms → 仍 ghost；无 resize 字段（旧输
  入形状）→ 仍 ghost；user/write 压过 resize；「最大化还原连续 5 帧序列」全
  程无 ghost。8 例新测试
- ghost 事件 data 附 `resize` 字段（最近尺寸变化距离），证据链更完整

### 交付二：诊断数据广度

- **第四条总线 sysDebug**（file:*/ipc:*/ai:*/lifecycle:*/res:*），与 anno/
  scroll/op 同形状；DevTools 出口 `__sysDebug`；devMode 订阅 + 诊断面板并入
  （标题改「批注+滚动+系统」，复制报告含环境行 + 系统计数器）
- **devContext**（新）：env 快照（版本/平台/窗口/DPR/主题/模式/big/最大化/
  侧栏，全惰性只读 DOM）+ 最近 16 操作环（click 目标描述符只对 ≤2 子元素读
  textContent 防大子树遍历；修饰键组合记键名；普通打字 2s 合并成一条
  "typing"）+ docInfo provider（App 注册，快照时现算一次：标签/字符/行/图
  片数）。**每条异常落盘附 ctx**（noteAnomaly 富集）——验收口径「拿到记录
  不看代码能定位场景」由它承载
- **tracedIo**（ipcTrace.ts）：包 tauriFs/fileOps/dialogs/clipboard 全部导出
  ——成功只进 `io.<kind>`/`io.ms.<kind>` 计数器，失败 emit `${kind}-fail`
  error 后**原样重抛**（零语义变化），>2s emit slow warn；**对话框 slowMs=
  Infinity**（时长=用户思考时间）；ai:request 同理不判慢
- **静默失败留痕**：autosave catch、watcher 启动失败、watcher 回读失败（原来
  全部无声吞掉）→ sysEmit；docCache hit/miss/put 计数
- **AI 链路**（ai.ts）：chat 失败 8001 / content 形态异常 8004（只记不抛）；
  chatStream 流错误事件与 invoke 双路 8002、done 缺失 8003、cancel 记 info
  abort
- **帧统计**：scrollDebug tick 顺带累计（帧数/>50ms 卡顿帧/最坏帧间隔/按键→
  下一帧延迟，每帧几次加减），`scrollFrameStats()` 快照不清零、心跳差分；
  心跳窗 ≥10 次掉帧→9001、≥8 次输入延迟→9003；warn 级位移 2s 内 ≥3 次→
  9002（devMode 侧维护时间戳环）
- **心跳扩容**：env + doc + frame + 四总线 counters + self（两 batcher 快照/
  writeFailures/mergedAlerts/uptime）——「一条心跳 = 当时的世界」
- 生命周期：useMilkdown `lifecycle:editor-ready`（createMs/sinceBootMs/big/
  seq）；App `lifecycle:mode-switch` + 模式/标签切语义埋点进操作环

### 教训与备忘

- **MD-1004 旧表达式保留**：原代码只读 `heightDelta`（layout:height 纯高度事
  件实际从不触发 1004），我顺手加 delta 兜底会扩大旧码触发面，按「旧码语义
  不变」红线撤回——细分新增码承载新触发面，别让旧码悄悄变脸
- 旧测试 `moveBlock→2001` 在细分后属于 2011：改用未分类 op 保住「2001 兜底」
  的测试意图，而不是删测试
- **Python heredoc 写源码被 Mimosa hook 拦截**（防绕过安全扫描）——源码一律
  Write/Edit 工具；且 heredoc 里 `\\n` 转义塌缩成真实换行写入过 App.tsx，
  Edit 修复——heredoc 打补丁模式今后只用于非源码，源码补丁全部走 Edit
- 规格「每条新归因规则都能脱离浏览器单测复现」是本次验证主载体：316 例全绿
  （基线 277 + 新 39）；GUI 场景手验清单已写入 CHANGELOG 待用户执行（侧栏/
