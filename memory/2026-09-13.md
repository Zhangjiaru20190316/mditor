### 安装过程踩坑（重要教训）

1. **官方下载中心强制华为账号登录**，且页面是 JS 动态渲染，curl/WebFetch 拿不到直链。用 ZCode 内置浏览器扫码登录解决的。
2. **IAB 二维码太小扫不上** → 把内置浏览器视口切到 430×800 移动布局后用户扫上了。下次登录二维码场景直接开小视口。
3. **IAB 大文件下载不可靠**：第一次下载完成后（2,479,948,594 字节满额）tmp 被浏览器丢弃没有重命名成正式文件。第二次下载满额后手动 `cp` 抢救成 `mditor-clt-6.0.2.670.zip`（PK 头校验通过）。**下次大文件优先想办法拿直链用 curl；浏览器下载要盯满额瞬间手动拷贝。**
4. 自写看门狗阈值单位搞错（2.4GiB 阈值 vs 实际 2.31GiB 满额）没触发——手动接管才对。满额判断应该用「连续 N 次无增长」而不是猜目标大小。
5. 解压用 `C:\Windows\System32\tar.exe -xf`（bsdtar 支持 zip 且路径处理比 info-zip unzip 稳），2.5GB/10 万文件约 2 分钟。
6. 本机 **无 Java**：hvigor 构建本身（Node 实现）不需要；AGC 签名（hap-sign-tool）需要 JDK 17，真机部署前再装。

## 白屏根修（同日午后）——resource://rawfile 的 CORS 拦截

- 现象：安装后窗口只停在静态开屏页。开屏是 index.html 静态 HTML，JS 不执行就不消失——据此与 main.tsx 4s 兜底矛盾锁定「JS 未执行」。
- 实锤日志（onConsole 看门狗转发）：`Access to script at 'resource://rawfile/web/assets/*.js' from origin 'null' has been blocked by CORS policy`——resource:// 协议 origin 为 null 且不在 ArkWeb 允许列表，ES module（CORS 模式）全灭。
- 修复：RawfileResponder 拦截 resource://rawfile/*，getRawFileContentSync 读字节自建响应（正确 MIME + ACAO:*）。commit c62a613。
- 排障经验：hilog -x 是环形缓冲且系统日志刷屏，grep 旧事件要用 tail；应用自家日志带 `A00D01/com.mditor.app/mditor` 域标签，前端 console 走 `JSAPP` 的 `[web` 前缀。
- 设备锁屏（带密码）导致无法自动化重启验证——修复已装（sign+install 成功），等用户解锁开 App 验证。
