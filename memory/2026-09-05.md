## mditor AI Agent 化改造：产出一次性改动提示词

- **痛点**：现有 AI 面板只是"带笔记上下文的纯对话"，AI 无法实际操作笔记。
- **产出**：`prompt-agent-overhaul.md`（工作区根目录，与 prompt-project-overhaul.md 同款格式），可整份粘贴给 AI 编码代理一次性执行。
- **用户确认的四项决策**：
  1. 独立模式切换（AI 面板顶部「对话 / Agent」开关，普通对话不动）
  2. 写入策略可配置（默认 diff 确认；auto 仅限当前笔记内容编辑，FS 操作强制确认）
  3. 全功能工具集（读/检索/编辑/追加/新建/重命名/删除→回收站/大纲，共 10 个工具）
  4. 批量整理一期就支持（ChangePlan 暂存 + 统一审阅）
- **核心架构**：前端驱动 Agent Loop（Rust 保持哑管道：ai.rs 加 tools 透传 + SSE tool_calls 增量聚合 + 新事件 ai_stream_tool_calls）；写操作全部"暂存-审阅-应用"，编辑器写入复用 EditorHandle。
- **关键约束**：CSP 锁 connect-src（LLM 走 Rust invoke）；Ollama 降级路径；trash > rm 红线；ChatMessage 序列化向后兼容（skip_serializing_if）。

## Mditor SVG 宣传动画

- **产出**：`promo/mditor-promo.svg` —— 自包含 1280×720 SVG，纯 CSS 动画 14s 无限循环（零 JS，README `<img>` / 浏览器直开均可播放）。
- **分镜时间轴**：0-2.5s Logo 描边+标题 / 2.4-8.4s 编辑器窗口「打字 Markdown 源码 → 所见即所得渲染」/ 8.4-11s 特性徽章五枚（多窗口/双链/公式/AI/LaTeX）+ 标语「为深度写作与知识管理而生」/ 11-14s 结尾卡（官网地址 + 开源 MIT / 本地优先 / Windows）。
- **品牌一致**：色板取自官网（`#8b5cf6` 紫 + `#4da3ff` 蓝，深蓝底 `#0f172a`）。
- **落地**：已挂 `mditor/README.md` 顶部横幅（仓库内路径 `docs/assets/mditor-promo.svg`）；`promo/frames/` 存了 6 张关键帧静图（无头 Edge + Web Animations API 冻结时间轴截的，可当各平台封面图）。
- **经验**：无头 Edge 对 SVG 内 CSS 动画的 `--virtual-time-budget` 截图不可靠，需包一层 HTML 用 `document.getAnimations()` 手动 pause+seek 再截。
