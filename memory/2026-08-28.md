### 新坑（本轮踩到）

- **HMR 旧模块测量坑**：页面里 `import('/src/lib/x.ts')` 在 HMR 后命中模块注册表
  旧版本——测量必须 `?t=Date.now()` cache-buster，否则跑旧代码得出「修复无效」假结论。
- **TaskStop 杀 tauri dev 后 mditor.exe 幸存**持单实例锁 → 下次 dev 启动秒退
  （exit 0 无报错！）；必须 taskkill /IM mditor.exe /T 补刀 + netstat 查 1420。
- CDP Input.dispatchKeyEvent 的 modifiers 用位掩码整数（Ctrl=2），字符串枚举
  'ctrl'/'Ctrl' 都报 Invalid parameters（'Control' 应该行但没试）。
- tracedIo 的 io.ms.* 计壁钟：主线程拥堵会把 IPC 回包记账成「写盘慢」
  （37s/write 假象）——读 io 计数先想主线程状态。
