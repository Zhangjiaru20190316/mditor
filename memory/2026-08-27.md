### 教训（IAB 浏览器实测）
- **首帧截图会撞 CSS 入场动画的 backwards fill**：动画时钟被环境冻结时
  （后台 tab/首帧 capture），`fill-mode: backwards` 让 hero 整块 opacity:0，
  截图像素空白但 DOM 正常。reload 后前台播放即正常——真实用户无感知，
  但今后做「内容默认隐藏」型入场要意识到这个坑。
- **IAB guest 合成器会丢文档层**：反复 hash 导航后整页只画 fixed 层（导航/
  进度条），DOM 诊断（reveal 计数、.has-js、#demo-input 已填）全部正常。
  判定方法：locator 读 DOM 状态 vs 像素截图对不上 → 环境渲染 bug，换新 tab
  即恢复。cua.scroll 大步长会 30s 超时（平滑滚动冲突），用 End/Home 键代替。

## mditor 大文档卡顿治理（v4.6.0 性能篇，已完成）

任务：消日志里 152KB/3447 行 KaTeX 文档的 MD-1003（1.2~1.5s × 24）与
MD-9001（单窗 77~103 掉帧）。全程测量驱动，产出 perf/ 基建 + 两个根修 + 评估。

### 方法论（可复用）
- 真实日志先读：dev-anomalies.log 聚合（MD-1003×24 / MD-9001×52 / MD-1011
  全量替换×17 / MD-1002 位移×53）→ 时间线对齐 dev-events.log → 问题档案。
- 测量：`tauri dev --config tauri.dev.conf.json`（独立 identifier
  com.mditor.app.dev，避开单实例转发+不碰用户状态）+ WebView2
  `--remote-debugging-port` + 自写零依赖 CDP（Node 原生 WebSocket）。
- 坑：tauri.dev.conf.json 不会被 tauri dev 自动合并（exe 里无 .dev 标识），
  必须 `--config` 显式传；seed mditor.json 时 JSON 反斜杠会被吃（用正斜杠）；
  测试打字会经 autosave 写文档——必须用副本（perf/fixtures，gitignore）。

### 两个根修（均已单独提交）
1. **聚焦切换全文档样式重算（主犯）**：crepe 只在 .ProseMirror-focused 定义
   `--prosemirror-virtual-cursor-color` → 失焦/回焦时该变量在「无→有」翻转 →
   Blink 作废全部后代样式。blur→focus() 实测 762ms（用户侧=点工具栏再点回
   正文，正是 MD-1003 的反复来源）。修复=global.css 让变量恒定存在（值不变
   → no-op）→ 0ms。**教训：CSS 自定义属性挂在状态类上=全子树样式重算雷。**
2. **虚拟光标每事务强制布局读**：prosemirror-virtual-cursor 每事务/
   selectionchange/ResizeObserver 同步读 DOM 选区 rect（脏布局=全文档同步
   布局，773ms/3clicks）。patch-package：rAF 合并+(doc,head,width) 同位跳过。

### 数据（221KB 同型文档，七场景基准）
- 点击×10：max 945→167ms，>200ms 长任务 1→0，事件 p95 976→192ms（p50 24 不变）
- 双击+sel-btn 加粗：0 长任务（用户日志原 1.2~1.5s）
- 打开仍是 ~2s 长任务：实测与解析无关（221KB 解析 <5ms），100% 是首次全量
  布局（PM updateStateInner 的 focusNode 读触发）；c-v 是唯一杠杆。
- big 档对照：打开 3411→1291ms、打字 p95 144→32ms、滚动 p95 65→6ms。
- **阈值结论**：对 ≤221KB 文档解析可忽略，降 docCache 阈值/解耦 worker 预解析
  无可测收益（本轮不做）；big 档默认保持关（铁律），但值得在文档里推荐
  3000 行+用户开启。

### 走过的弯路（别再走）
- scrollDebug tick 每帧双读哨兵 rect（A/B 实验：停用后 1939→1853ms，非主犯）。
- floating-ui TooltipProvider observeMove 轮询（profile 归因 750ms）：打补丁
  实测无差异（1268→1262ms）——它只是替同帧绘制预付布局款，**不是寄生成本**，已回退。
- 打字 ~140ms 延迟是 dev 构建+CDP 合成输入的固定开销（用户生产日志
  worstInputLagMs=6ms），非真问题。
- 160+ 表格/列表拖拽句柄 TooltipProvider 常驻 DOM（问题文档表格多），确认隐藏态无轮询成本。
