**经验教训**：
- `| tail` 管道会缓冲子进程全部输出——长跑脚本要直接流式看，别套 tail（浪费两轮排查时间）。
- bash heredoc 写文件会被 Mimosa 钩子拦，改用 Write 工具。
- stash 前端代码做 A/B 时，vite HMR 会抓到「import 缺文件」的坏瞬间——恢复后要强刷页面再测。
- 用户正式版 mditor.exe（AppData\Local\Mditor）与 dev 实例同机同名，杀进程前必须按 Path 区分。
- lint 的 118 个错误是 HEAD 预存（perf/*.mjs no-undef），与改动无关——基线没跑 lint 就开始改，中途才发现，应引以为戒。
