# 2026-08-25

## mditor v4.4.0：多根工作区（VS Code 式 Multi-root Workspace）

用户诉求：不同工作区之间切文件太麻烦 → 选定方向「多开工作区，类似 VS Code」。

### 交付内容

- **store**：`workspaces: string[]` 取代单值 `workspace`（首启幂等迁移，旧键
  删除）；`recentWorkspaces`（上限 8，内存镜像同 recent 模式）供空态快速重开
- **新 lib/workspaces.ts**：samePathFold / isUnderRoot / rootOf / dedupeRoots
  / normalizeStoredWorkspaces 全纯函数（大小写折叠 + 分隔符边界）——
  FileTree 原有 isUnderPath/samePath 提取到此消重
- **FileTree 多根**：每根一个可折叠分区（chevron + 根名 + hover ×移除）；
  childrenMap/expanded 本就按绝对路径键控，跨根天然唯一 → prune 改
  underAnyRoot 即可，**FileNode 零改动**。关键 deps：`roots.join("\n")`
  而非数组身份。折叠只藏行不丢状态（再展开零 IO）
- **App**：废除「打开外部文件劫持工作区」（旧行为静默换树丢展开状态）；
  新增 add/replace/remove 根操作（replace 在 ≥2 根时确认；remove 无确认
  ——磁盘不动）；侧栏头 ＋添加 / ⤢替换 双按钮；空态列最近工作区
- **搜索**：searchWorkspaces(roots) 逐根收集、maxFiles 预算全局共享；
  WorkspaceSearch 的 lastSearch key 加 scopeKey（根列表+排除项全量
  join）——修掉「切工作区后同 query 不重扫」的旧隐患
- 菜单：文件 →「添加文件夹到工作区…」（MenuBar.tsx + lib.rs menu_ids
  ADD_FOLDER，macOS 原生菜单同构）
- SettingsModal 的 workspace prop 传 roots[0]（排除项相对路径显示基准）

### 教训

- **后台构建与后续编辑竞态**：tauri build 后台跑时又 Edit 了源码，vite
  产物是否含该改动无法确证（minified 后 grep 不可靠）→ 重跑一次 build
  收尾（cargo 增量只花 1 分钟）。今后：构建启动后不再改源码，或收尾必跑
  一次最终构建
- 编辑大块代码时 old_string 圈太大误删了仍在用的 sameEntries（靠后续读
  回补）——大编辑后立即 grep 关键符号核对
