Guide

操作说明

覆盖全部功能，五分钟上手

1

打开文件夹

「文件 → 打开文件夹」选择你的笔记目录，工作区文件树自动加载；也可以直接把 .md 文件拖进窗口快速打开。

2

开始写作

所见即所得，像用 Word 一样写 Markdown：表格、公式、任务清单、代码块全部实时渲染，状态栏实时显示字数。

3

保存与导出

Ctrl+S 随时保存，关闭窗口前脏标签自动落盘；写完导出 PDF / PNG 长图 / Word / HTML，或复制为富文本。

核心优势

  • 5 MB 安装包，秒开
  • 本地优先，文件永远属于你
  • 零遥测，无广告无上报
  • AI 助手，自带多模型预设
  • 大文档不卡，滚动零漂移
  • 完全开源，MIT 协议

1 · 写作与格式化

主编辑区干净专注：标题、加粗（Ctrl+B）、高光（Ctrl+Shift+H）、文字颜色、斜体、删除线、行内代码全部即输即得；选中文字会弹出浮动工具栏，链接、图片、脚注一键插入。

底部状态栏显示文档名、字数与当前模式；侧边栏（Ctrl+\）与 AI 面板（Ctrl+I）随时开关。

2 · 三种编辑模式

状态栏下拉一键切换，初稿阶段用所见即所得，快速浏览用即时渲染，精确控制格式切源码模式——同一份文档随时互换，内容不会丢失。

切换模式会重建编辑器以释放内存，大文档长时间编辑也不卡顿。

3 · 工作区与文件管理

文件树：懒加载目录，深层文件夹即点即开，新建 / 重命名 / 删除 / 批量多选
多标签页：Ctrl+Tab 轮换，Ctrl+W 关闭，脏标签切走自动保存
外部修改监听：磁盘文件被其他程序修改时自动同步，有冲突先确认
关窗自动保存：关闭窗口 / 退出前，所有脏标签自动写回磁盘
拖放打开：把 .md 文件拖进窗口即开新标签；双击文件转发给已运行实例
最近文档：侧边栏「最近」标签，找回上次写的东西
全局搜索：Ctrl+Shift+F 跨文件搜索，点击结果精确定位到匹配行
模板新建：会议纪要 / 周报 / 阅读笔记等内置模板，秒开常用结构

4 · 从模板新建

「文件 → 从模板新建」内置空白文档、会议纪要、周报、阅读笔记、写作提纲等多种模板，日期自动填充，新建即用。

也支持从本地文件新建：Ctrl+N 新建空文档，Ctrl+O 打开任意 .md 文件。

5 · 大纲导航

侧边栏「大纲」自动提取全文标题，长文结构一目了然；列表再长也流畅滚动，点击任意标题即平滑跳转。

侧边栏五个标签切换：文件树 / 大纲 / 最近 / 批注 / 搜索，批注标签带数量角标。

6 · 行内批注

选中任意文字点浮动工具栏的「批注」，即在该处生成脚注式标记；点击标记查看内容，随时编辑或删除。

AI 助手回复也可以一键「批注」——把回答精炼成一条笔记挂在原文上，适合论文批注、代码评审。

7 · AI 助手

支持任意 OpenAI 兼容接口（自定义 BaseURL / Key / 模型），内置 DeepSeek、智谱 GLM、Kimi、OpenRouter、Ollama 本地模型预设，多套配置可切换。

选中文字即可改写、翻译、解释、续写；SSE 流式输出，支持追问与改动审查；所有请求经本地 Rust 代理转发，不会直连外网。

8 · 设置与个性化

「帮助 → 设置」左导航双栏布局，约 20 项设置按功能分区：外观（五套主题、字体、动效强度三档）、排版（字号 / 行高 / 段距）、编辑行为、性能与诊断、AI 助手、快捷操作、工作区。

所有设置保存在本机 mditor.json，换机器不带走任何数据——隐私与便携都归你。

9 · 大文档性能与安全

滚动零漂移：内容寻址高度记忆 + 分块预热，跳转落点精确到 48px 内
大文档性能模式：超过阈值自动关闭代码高亮与公式渲染，打字依旧流畅
内存守护：软重建 + 会话快照自愈，异常后自动恢复文档
严格 CSP：无 unsafe-eval，AI 请求全部经 Rust 侧代理
HTML 消毒：AI 回复与批注渲染管线内置 rehype-sanitize
无遥测：不采集任何使用数据，出站请求仅你配置的 AI 接口

FAQ

常见问题

支持 macOS / Linux 吗？

目前发布 Windows 10/11 版本（WebView2）。macOS / Linux 在计划中，欢迎在 GitHub Issues 提出需求。

我的数据会被上传吗？

不会。文档就是本地磁盘上的 .md 文件，设置与最近文件存于本机 mditor.json。应用无遥测、无广告、无任何数据上报；唯一的网络请求只有你主动配置的 AI 接口，且经本地 Rust 代理转发。

为什么没有自动更新？

v3.5.0 起移除了自动更新器（原端点为占位符，无法工作）。手动到 Releases 页下载新版本即可，安装包仅 5 MB。

AI 功能需要付费吗？

AI 助手本身免费，但需要你自己配置模型接口（OpenAI 兼容即可，也可以用 DeepSeek、智谱、Kimi 或本地 Ollama）。不配置 AI 也不影响任何写作功能。

大文档会卡吗？

不会。超过阈值自动进入性能模式（关闭代码高亮与公式渲染）；v4.1.1 起大文档滚动零漂移——3894 行实测文档中，大纲跳转落点偏差仅 48px，长时间编辑无可感知掉帧。
